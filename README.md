# 담다

영상 링크 하나로 받기 → 제목·대본·리액션 → 나레이션 → CapCut 프로젝트까지 만들어 주는 Windows 앱입니다.

## 설치

1. [최신 버전 받기](https://github.com/dkfptmzld/damda-releases/releases/latest) 에서 `damda_x.x.x_x64-setup.exe` 를 내려받아 실행합니다.
2. "Windows의 PC 보호" 창이 나오면 **추가 정보 → 실행**을 누릅니다. (개인이 만든 프로그램이라 나오는 안내입니다.)
3. 담다를 켜고 **회원가입**을 한 뒤, 관리자의 승인을 기다립니다.

한 번 설치하면 새 버전은 앱이 알아서 알려 줍니다. 상단의 **지금 업데이트**만 누르면 됩니다.

## 필요한 것

- Windows 10/11 (64비트)
- CapCut (프로젝트를 열어 편집하려면)
